## 新增 / Added

- 便笺内点击任务复选框（`[ ]` / `[x]`）即可勾选或取消，支持撤销；代码块内的标记不会被误触。编辑窗口新增「插入任务」按钮，右键菜单与工具栏均可使用；绳上卡片右上角显示任务完成进度（n/m）。
- 编辑窗口新增「截图」按钮和右键菜单「截图插入…」：框选屏幕任意区域，图片自动插入当前便笺光标处；截图期间便笺窗口自动隐藏，按 Esc 取消。首次使用需在「系统设置 › 隐私与安全性 › 屏幕录制」中授权。
- 新增任务标记定位、切换与进度统计的隔离测试（tests/check-tasks.py）。

- Click a task checkbox (`[ ]` / `[x]`) in a note to toggle it, with undo support; markers inside fenced code stay literal. A new "Insert Task" toolbar item works alongside the context menu, and the rope card shows an n/m progress badge.
- New "Screenshot" toolbar button and context menu item: capture any screen region and insert it at the cursor. The note window hides during capture; press Esc to cancel. Grant Screen Recording permission in System Settings on first use.
- Isolated tests for task marker lookup, toggling, and progress counting (tests/check-tasks.py).
